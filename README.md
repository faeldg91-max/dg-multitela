# DG Multitela

Aplicativo para Windows para organizar várias janelas do navegador em uma tela.

## Download e instalação

Versão atual: **1.3.2**

1. Abra a [página de versões](https://github.com/faeldg91-max/dg-multitela/releases/latest).
2. Em **Assets**, baixe `DG_Multitela_1.3.2_Setup.exe`.
3. Execute o instalador no Windows.

## Atualizações

Na tela inicial, **Verificar versão** consulta a publicação mais recente em GitHub Releases. Quando encontra uma versão superior, oferece o download do instalador.
