# DG Multitela

Aplicativo para Windows desenvolvido para facilitar o uso de múltiplas telas.

## Download

Versão atual: **DG Multitela 1.3**

➡️ [Baixar a versão mais recente](https://github.com/faeldg91-max/dg-multitela/releases/latest)

O instalador oficial é distribuído pela seção **Releases** deste repositório.

## Como instalar

1. Acesse a página de download acima.
2. Abra a versão mais recente.
3. Em **Assets**, baixe o arquivo `DG_Multitela_1.3_Setup.exe`.
4. Execute o instalador no Windows.
5. Siga as instruções apresentadas pelo instalador.

## Atualizações

As novas versões do DG Multitela serão publicadas neste repositório.

Para segurança, utilize sempre o instalador disponibilizado na página oficial de Releases.
